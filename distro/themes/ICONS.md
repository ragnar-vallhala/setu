# Setu icon names

This is the list of icon names that Setu components look up in a theme
pack. Packs and icon sets are described in [docs/THEMES.md](../../docs/THEMES.md).
If you add a name to a component, add it here in the same change. The
shell's names are defined in `shell/src/setu-theme.h` (`SETU_ICON_NAMES`),
together with the built-in glyph each one falls back to.

## Where a name is looked up

A name is resolved in this order. The first file that exists wins.

1. **The pack's own `icons/index.ini`, and those of the packs it derives from.**
   The pack closest to the active one comes first: a pack with
   `Base=setu-light` overrides setu-light's icons.
2. **An icon set**, when `theme.ini` has `[Icons] set=<name>`.
   - The set is looked up in `%LOCALAPPDATA%\Setu\Icons\<name>\index.ini`
     (a user's sets) first, then in
     `%WINDIR%\Resources\Setu\Icons\<name>\index.ini`. The installed sets
     are `setu-line`, `setu-bold`, `setu-duotone`, `setu-solid` and
     `setu-colour`, generated by `art/icons/icongen.py`.
   - A set named by a pack ranks just ahead of that pack's own
     `index.ini` and the `index.ini` files of its bases. A pack that
     derives from it still overrides single icons with its own
     `index.ini`.
3. **The built-in glyph** compiled into the program: a Lucide copy, or
   the Setu bridge mark.

In `index.ini`, paths are relative to the folder of that `index.ini`:

```ini
[Icons]
folder=folder.ico
```

## Glyphs and full-colour icons

setu-shell and setu-files draw each `.ico` at the size they need.

**Monochrome icons are glyphs.** An icon is monochrome when every pixel
that is at least half opaque has the same colour, within 40 per channel.
Glyphs are drawn in the colour token of the place they appear (`text`,
`text-secondary`, `accent`, `accent-text`, `taskbar-text`, `logo`, and so
on), so one glyph works in light and dark packs. Draw glyphs in a single
colour; `#1B1B1B` is the convention.

**Any other icon is full-colour.** It is drawn as it is, with its alpha.

## Names

The "Used by" column uses these short names:

- **shell**: setu-shell, which draws the taskbar, Start menu and run box.
- **files**: setu-files.
- **frames**: the window frames drawn by the Setu personality.
- **Shell Icons**: the `Shell Icons` registry key that `setu-theme apply`
  writes, so other Windows programs see the icon. The number is the
  key's value name; see the next section.

## Shell Icons

`setu-theme apply` writes these values under
`HKLM\Software\Microsoft\Windows\CurrentVersion\Explorer\Shell Icons`:

- Each value is named by the index of a shell stock icon, as in the
  `SHSTOCKICONID` enumeration:
  https://learn.microsoft.com/windows/win32/api/shellapi/ne-shellapi-shstockiconid
- Each value's data is `"<path>,0"`.
- A value is deleted when the active pack has no icon for its name.

| Index | `SHSTOCKICONID` | Name |
|---|---|---|
| 0 | `SIID_DOCNOASSOC` | `file` |
| 3 | `SIID_FOLDER` | `folder` |
| 4 | `SIID_FOLDEROPEN` | `folder-open` |
| 7 | `SIID_DRIVEREMOVE` | `drive-removable` |
| 8 | `SIID_DRIVEFIXED` | `drive-fixed` |
| 11 | `SIID_DRIVECD` | `drive-optical` |
| 15 | `SIID_MYCOMPUTER` | `computer` |
| 31 | `SIID_RECYCLER` | `recycle-bin-empty` |
| 32 | `SIID_RECYCLERFULL` | `recycle-bin-full` |

## Sizes

Give each `.ico` these sizes: 16, 20, 24, 32, 48, 64 and 256 px. The shell
draws:

| Where | Size at 96 DPI |
|---|---|
| Toolbar, Places and menu glyphs | 16 to 20 |
| Taskbar icons, including the Start button | `taskbar-icon`, 24 by default |
| List icons | 16 in details view, 32 or 48 in icons view |

Sizes are scaled for DPI.
